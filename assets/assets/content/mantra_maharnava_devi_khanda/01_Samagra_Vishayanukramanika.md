# ಮಂತ್ರ ಮಹಾರ್ಣವ (ದೇವೀ ಖಂಡ) - ಸಮಗ್ರ ವಿಷಯಾನುಕ್ರಮಣಿಕಾ

| ತರಂಗ | ತರಂಗದ ಹೆಸರು / ಮುಖ್ಯ ವಿಷಯಗಳು | ಮೂಲ ಪುಟ ವ್ಯಾಪ್ತಿ |
| :--- | :--- | :--- |
| **ತರಂಗ ೧** | **ಗಾಯತ್ರೀ ತಂತ್ರ :** ಬ್ರಹ್ಮಗಾಯತ್ರೀ ಪುರಶ್ಚರಣ, 24 ವರ್ಣ ಋಷಿ-ಛಂದ-ದೇವತೆ, ಶಾಪವಿಮೋಚನ, 50+ ದೇವತಾ ಗಾಯತ್ರಿಗಳು, ಕವಚ, ಪಂಜರ, ಸ್ತವರಾಜ, ಸಹಸ್ರನಾಮ, ಉಪನಿಷತ್, ಚಕ್ರ. | ಪುಟ ೧ - ೬೦ |
| **ತರಂಗ ೨** | **ದುರ್ಗಾ ತಂತ್ರ :** ದುರ್ಗಾಪಟಲ, ನವಾರ್ಣ ಮಂತ್ರ, ದುರ್ಗಾಸಪ್ತಶತೀ ಕ್ರಮ, ಚಂಡೀ ವಿಧಿ, ಶತಚಂಡೀ-ಸಹಸ್ರಚಂಡೀ, ದುರ್ಗಾ ಕವಚ, ಸಹಸ್ರನಾಮ, ದುರ್ಗಾ ಸ್ತೋತ್ರಗಳು. | ಪುಟ ೬೧ - ೨೮೪ |
| **ತರಂಗ ೩** | **ಕಾಳಿಕಾ ತಂತ್ರ :** ದಕ್ಷಿಣಕಾಳಿಕಾ (೨೨ ಅಕ್ಷರ), ಭದ್ರಕಾಳೀ, ಗುಹ್ಯಕಾಲೀ, ಕಾಳೀ ಕವಚ, ಸಹಸ್ರನಾಮ, ಶತನಾಮ, ಧ್ಯಾನ, ಯಂತ್ರ, ಬಲಿವಿಧಾನ. | ಪುಟ ೨೮೫ - ೩೭೮ |
| **ತರಂಗ ೪** | **ತಾರಾ ತಂತ್ರ :** ಉಗ್ರತಾರಾ, ಏಕಜಟಾ, ನೀಲಸರಸ್ವತೀ, ತಾರಾ ಕವಚ, ಸಹಸ್ರನಾಮ, ಅಕ್ಷೋಭ್ಯ ಋಷಿ ಪೂಜೆ, ತಾರಾ ಸ್ತೋತ್ರ, ಯಂತ್ರ ಸಾಧನೆ. | ಪುಟ ೩೭೯ - ೪೧೭ |
| **ತರಂಗ ೫** | **ಸರಸ್ವತೀ ತಂತ್ರ :** ವಾಗ್ದೇವೀ, ಸರಸ್ವತೀ ಮಂತ್ರಗಳು, ಕವಚ, ಸಹಸ್ರನಾಮ, ಮೇಧಾವೃದ್ಧಿ, ವಾಕ್ಸಿದ್ಧಿ. | ಪುಟ ೪೧೮ - ೪೨೯ |
| **ತರಂಗ ೬** | **ಷೋಡಶೀ (ಶ್ರೀವಿದ್ಯಾ ತ್ರಿಪುರಸುಂದರೀ) ತಂತ್ರ :** ಷೋಡಶೀ, ಪಂಚದಶೀ, ಬಾಲಾತ್ರಿಪುರಾ, ತ್ರಿಪುರಸುಂದರೀ ಕವಚ, ಶ್ರೀವಿದ್ಯಾ ಕವಚ, ಸಹಸ್ರನಾಮ, ಹೃದಯ. | ಪುಟ ೪೩೦ - ೪೬೦ |
| **ತರಂಗ ೭** | **ಭುವನೇಶ್ವರೀ ತಂತ್ರ :** ಭುವನೇಶ್ವರೀ ಏಕಾಕ್ಷರೀ & ತ್ರ್ಯಕ್ಷರ ಮಂತ್ರ, ತ್ರೈಲೋಕ್ಯಮಂಗಲ ಕವಚ, ಸಹಸ್ರನಾಮ, ಅಷ್ಟೋತ್ತರ, ಹೃದಯ. | ಪುಟ ೪೬೧ - ೪೭೮ |
| **ತರಂಗ ೮** | **ತ್ರಿಪುರಭೈರವೀ ತಂತ್ರ :** ತ್ರಿಪುರಭೈರವೀ ಮಂತ್ರ, ಭೈರವೀ ಕವಚ, ಸಹಸ್ರನಾಮ, ಸ್ತವರಾಜ, ಅಷ್ಟೋತ್ತರ ಶತನಾಮ. | ಪುಟ ೪೭೯ - ೪೯೩ |
| **ತರಂಗ ೯** | **ಛಿನ್ನಮಸ್ತಾ ತಂತ್ರ :** ಸಪ್ತದಶಾಕ್ಷರ ಮಂತ್ರ, ಪ್ರಚಂಡಚಂಡಿಕಾ, ಛಿನ್ನಮಸ್ತಾ ಕವಚ, ಸಹಸ್ರನಾಮ, ಸ್ತೋತ್ರ, ಹೃದಯ. | ಪುಟ ೪೯೪ - ೫೧೧ |
| **ತರಂಗ ೧೦** | **ಧೂಮಾವತೀ ತಂತ್ರ :** ಅಷ್ಟಾಕ್ಷರ ಧೂಮಾವತೀ ಮಂತ್ರ, ಕವಚ, ಸಹಸ್ರನಾಮ, ದಾರಿದ್ರ್ಯನಾಶಕ ಪ್ರಯೋಗ, ಸ್ತೋತ್ರ. | ಪುಟ ೫೧೨ - ೫೨೪ |
| **ತರಂಗ ೧೧** | **ಬಗಳಾಮುಖೀ ತಂತ್ರ :** ೩೬ ಅಕ್ಷರಗಳ ಬಗಳಾಮುಖೀ ಮಹಾಮಂತ್ರ, ಪೀತಾಂಬರಾ ಕವಚ, ಸಹಸ್ರನಾಮ, ಸ್ತೋತ್ರ, ಸ್ತಂಭನ ಪ್ರಯೋಗ. | ಪುಟ ೫೨೫ - ೫೫೨ |
| **ತರಂಗ ೧೨** | **ಮಾತಂಗೀ ತಂತ್ರ :** ದ್ವಾತ್ರಿಂಶದಕ್ಷರ ಮಾತಂಗೀ, ಲಘು ಶ್ಯಾಮಲಾ, ಸುಮುಖೀ, ಕವಚ, ಸಹಸ್ರನಾಮ, ಹೃದಯ. | ಪುಟ ೫೫೩ - ೫೭೧ |
| **ತರಂಗ ೧೩** | **ಕಮಲಾತ್ಮಿಕಾ (ಮಹಾಲಕ್ಷ್ಮೀ) ತಂತ್ರ :** ಏಕಾಕ್ಷರ, ಚತುರಕ್ಷರ, ಸಪ್ತವಿಂಶತ್ಯಕ್ಷರ, ದ್ವಾದಶಾಕ್ಷರ ಮಹಾಲಕ್ಷ್ಮೀ, ಸಿದ್ಧಲಕ್ಷ್ಮೀ, ಜ್ಯೇಷ್ಠಾಲಕ್ಷ್ಮೀ, ಕವಚ, ಸೂಕ್ತ, ಸಹಸ್ರನಾಮ. | ಪುಟ ೫೭೨ - ೬೦೮ |
| **ತರಂಗ ೧೪** | **ಕುಮಾರೀ ತಂತ್ರ :** ಕುಮಾರೀ ಭೇದಗಳು, ಕುಮಾರೀ ಪೂಜಾ ಪ್ರಯೋಗ, ಕವಚ, ಸ್ತೋತ್ರ, ಸಹಸ್ರನಾಮ, ಕುಮಾರೀ ತರ್ಪಣ. | ಪುಟ ೬೦೯ - ೬೩೧ |
| **ತರಂಗ ೧೫** | **ಕಾಳಿಂದೀ (ಯಮುನಾ) ತಂತ್ರ :** ಯಮುನಾ ಮಂತ್ರ ಪಟಲ, ಕವಚ, ಸ್ತವ, ಸಹಸ್ರನಾಮ. | ಪುಟ ೬೩೨ - ೬೪೪ |
| **ತರಂಗ ೧೬** | **ಮಿಶ್ರ ತಂತ್ರ - ೧ :** ಆಸುರೀ ಮಹಾಕಲ್ಪ, ಕಾಳರಾತ್ರಿ, ಷಟ್ಕರ್ಮ ವಿಧಾನ (ವಶೀಕರಣ, ಸ್ತಂಭನ, ಮೋಹನ, ಆಕರ್ಷಣ, ಉಚ್ಚಾಟನ, ವಿದ್ವೇಷಣ), ವಾರ್ತಾಳೀ (ವಾರಾಹೀ). | ಪುಟ ೬೪೫ - ೬೬೨ |
| **ತರಂಗ ೧೭** | **ಮಿಶ್ರ ತಂತ್ರ - ೨ :** ಮಹಿಷಮರ್ದಿನೀ, ರೇಣುಕಾಶಬರೀ, ಅನ್ನಪೂರ್ಣಾ (ಮಂತ್ರ, ಕವಚ, ಸ್ತೋತ್ರ), ಪೃಥ್ವೀ, ಗಂಗಾ, ಮಣಿಕರ್ಣಿಕಾ, ಶೀತಲಾದೇವಿ, ಜ್ವಾಲಾಮುಖೀ, ಇಂದ್ರಾಕ್ಷೀ ಸ್ತೋತ್ರ, ಜೈನಮತ ಪದ್ಮಾವತೀ ಸ್ತೋತ್ರ & ಪುರಶ್ಚರಣ, ಸಮಗ್ರ ಯಂತ್ರ-ಚಿತ್ರಾವಳಿ. | ಪುಟ ೬೬೩ - ೭೫೪ |
