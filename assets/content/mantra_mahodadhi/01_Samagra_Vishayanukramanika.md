# ಮಂತ್ರ ಮಹೋದಧಿ - ಸಮಗ್ರ ವಿಷಯಾನುಕ್ರಮಣಿಕಾ (Master Table of Contents)

| **ತರಂಗ ೧** | **ಭೂತಶುದ್ಧಿ, ಪ್ರಾಣಪ್ರತಿಷ್ಠಾ, ಮಾತೃಕಾನ್ಯಾಸಗಳು ಹಾಗೂ ದೀಕ್ಷಾ ವಿಧಿ**<br>ಮಂಗಳಾಚರಣ, ಪ್ರಾತಃಕೃತ್ಯ, ಮಂತ್ರಸ್ನಾನ, ಭೂತಶುದ್ಧಿ ಕ್ರಮ, ಪ್ರಾಣಪ್ರತಿಷ್ಠಾ ಮಂತ್ರ, ಅಂತರ‍್ಮಾತೃಕಾ, ಸೃಷ್ಟಿ-ಸ್ಥಿತಿ-ಸಂಹಾರ ಮಾತೃಕಾನ್ಯಾಸ, ಪೀಠಶಕ್ತಿ ಪೂಜೆ, ದೀಕ್ಷಾ ಸಂಸ್ಕಾರ. | ಪುಟ ೩೯ - ೫೨ |
| **ತರಂಗ ೨** | **ಶ್ರೀ ಗಣಪತಿ ಮಂತ್ರ ಭೇದಗಳು ಹಾಗೂ ಪೂಜಾವಿಧಾನ**<br>ಮಹಾಗಣಪತಿ, ಹರಿದ್ರಾಗಣಪತಿ, ಉಚ್ಛಿಷ್ಟಗಣಪತಿ, ಲಕ್ಷ್ಮೀಗಣಪತಿ, ಹೇರಂಬ, ವಲ್ಲಭಾಗಣಪತಿ, ಗಣೇಶ ಯಂತ್ರ ರಚನೆ, ಧ್ಯಾನ, ಆವರಣ ಪೂಜೆ, ಪುರಶ್ಚರಣ, ಹೋಮ ಪ್ರಯೋಗಗಳು. | ಪುಟ ೫೩ - ೬೧ |
| **ತರಂಗ ೩** | **ಶ್ರೀ ಕಾಳಿಕಾ ಹಾಗೂ ಸುಮುಖೀ ಮಂತ್ರಗಳು**<br>ದಕ್ಷಿಣಕಾಳಿಕಾ (ದ್ವಾದಶಾರ್ಣ, ಪಂಚದಶಾರ್ಣ), ಭದ್ರಕಾಳೀ, ಗುಹ್ಯಕಾಲೀ, ಸುಮುಖೀ ಮಂತ್ರ, ಕಾಳಿಕಾ ಯಂತ್ರ, ಪೂಜಾಕ್ರಮ, ಆವರಣ ಪೂಜೆ, ಬಲಿಪ್ರದಾನ, ಸಿದ್ಧಿಲಕ್ಷಣ. | ಪುಟ ೬೧ - ೬೬ |
| **ತರಂಗ ೪** | **ಶ್ರೀ ತಾರಾ, ಏಕಜಟಾ ಹಾಗೂ ಉಗ್ರತಾರಾ ಮಂತ್ರಗಳು**<br>ತಾರಾ ಮಂತ್ರ (ಏಕಾಕ್ಷರ, ಅಷ್ಟಾಕ್ಷರ), ಉಗ್ರತಾರಾ, ಏಕಜಟಾ, ನೀಲಸರಸ್ವತೀ, ತಾರಾ ಯಂತ್ರ, ಧ್ಯಾನ, ಅಕ್ಷೋಭ್ಯ ಋಷಿ ಪೂಜೆ, ವಶೀಕರಣ & ವಿದ್ಯಾಪ್ರಾಪ್ತಿ ಪ್ರಯೋಗ. | ಪುಟ ೬೭ - ೭೬ |
| **ತರಂಗ ೫** | **ಶ್ರೀ ಛಿನ್ನಮಸ್ತಾ (ಪ್ರಚಂಡಚಂಡಿಕಾ) ಮಂತ್ರಗಳು**<br>ಛಿನ್ನಮಸ್ತಾ ಷೋಡಶಾರ್ಣ ಮಂತ್ರ, ವೈರೋಚನೀ, ಡಾಕಿನೀ, ವರ್ಣಿನೀ, ಧ್ಯಾನ, ಕವಚ, ಛಿನ್ನಮಸ್ತಾ ಯಂತ್ರ, ರಕ್ತಬಲಿ ರಹಸ್ಯ, ಭೋಗ-ಮೋಕ್ಷ ಸಿದ್ಧಿ. | ಪುಟ ೭೭ - ೮೯ |
| **ತರಂಗ ೬** | **ಶ್ರೀ ವಟುಕ ಭೈರವ ಹಾಗೂ ಸ್ವರ್ಣಾಕರ್ಷಣ ಭೈರವ ಮಂತ್ರಗಳು**<br>ವಟುಕ ಭೈರವ (ಏಕಾಕ್ಷರ, ಅಷ್ಟಾಕ್ಷರ, ಏಕವಿಂಶತ್ಯಕ್ಷರ), ಸ್ವರ್ಣಾಕರ್ಷಣ ಭೈರವ, ಆಪದುದ್ಧಾರಕ ಭೈರವ, ಭೈರವ ಯಂತ್ರ, ಬಲಿ, ದಾರಿದ್ರ್ಯನಾಶಕ & ರಕ್ಷಾ ಪ್ರಯೋಗ. | ಪುಟ ೮೯ - ೯೬ |
| **ತರಂಗ ೭** | **ಯಕ್ಷಿಣೀ, ಚೇಟಿಕಾ ಹಾಗೂ ಕರ್ಣಪಿಶಾಚಿನೀ ಮಂತ್ರಗಳು**<br>ಸುರಸುಂದರೀ, ರತಿಪ್ರಿಯಾ, ಕನಕಾವತೀ, ಕಾಮೇಶ್ವರೀ ಯಕ್ಷಿಣೀ, ವಟಯಕ್ಷಿಣೀ, ಕರ್ಣಪಿಶಾಚಿನೀ, ಚೇಟಿಕಾ ಮಂತ್ರಗಳು, ಪ್ರತ್ಯಕ್ಷ ಸಿದ್ಧಿ, ನಿಧಿ ದರ್ಶನ. | ಪುಟ ೯೬ - ೧೦೭ |
| **ತರಂಗ ೮** | **ಶ್ರೀ ಬಾಲಾ ತ್ರಿಪುರಸುಂದರೀ ಹಾಗೂ ಶ್ಯಾಮಲಾ ಮಂತ್ರಗಳು**<br>ಬಾಲಾ (ತ್ರ್ಯಕ್ಷರೀ, ಷಡಕ್ಷರೀ, ನವಾಕ್ಷರೀ), ಲಘು ಶ್ಯಾಮಲಾ, ಮಾತಂಗೀ, ಸುಮುಖೀ, ವಾಗ್ವಾದಿನೀ, ಬಾಲಾಯಂತ್ರ, ಕವಚ, ವಿದ್ಯಾ-ವಾಕ್ ಸಿದ್ಧಿ ಪ್ರಯೋಗಗಳು. | ಪುಟ ೧೦೭ - ೧೨೪ |
| **ತರಂಗ ೯** | **ಶ್ರೀ ಬಗಳಾಮುಖೀ ಹಾಗೂ ಸ್ವಪ್ನವಾರಾಹೀ ಮಂತ್ರಗಳು**<br>ಬಗಳಾಮುಖೀ (ಪೀತಾಂಬರಾ) ಅಷ್ಟಾದಶಾಕ್ಷರ ಮಂತ್ರ, ಸ್ತಂಭನ ವಿದ್ಯಾ, ಸ್ವಪ್ನವಾರಾಹೀ, ಶತ್ರುನಿಗ್ರಹ ವಾರಾಹೀ, ಯಂತ್ರ, ಹಳದಿ ಪುಷ್ಪಾರ್ಚನೆ, ಜಯಪ್ರಯೋಗ. | ಪುಟ ೧೨೪ - ೧೩೭ |
| **ತರಂಗ ೧೦** | **ಶ್ರೀ ಧೂಮಾವತೀ, ಭುವನೇಶ್ವರೀ ಹಾಗೂ ಕಮಲಾ ಮಂತ್ರಗಳು**<br>ಧೂಮಾವತೀ ಮಂತ್ರ (ಅಷ್ಟಾರ್ಣ), ಭುವನೇಶ್ವರೀ ಮಂತ್ರ (ಏಕಾಕ್ಷರೀ, ಮಾಯಾಬೀಜ), ಕಮಲಾ (ಮಹಾಲಕ್ಷ್ಮೀ), ಜ್ಯೇಷ್ಠಾಲಕ್ಷ್ಮೀ, ದಾರಿದ್ರ್ಯಹರಣ & ಸರ್ವಸಂಪತ್ಪ್ರದ ಯಂತ್ರ-ಮಂತ್ರಗಳು. | ಪುಟ ೧೩೭ - ೧೪೩ |
| **ತರಂಗ ೧೧** | **ಶ್ರೀವಿದ್ಯಾ ಮಹಾತ್ರಿಪುರಸುಂದರೀ ಹಾಗೂ ಷೋಡಶೀ ಮಂತ್ರಗಳು**<br>ಪಂಚದಶಾಕ್ಷರೀ, ಷೋಡಶೀ, ಕಾದಿ-ಹಾದಿ ಮತಗಳು, ಷೋಢಾನ್ಯಾಸ (ಗಣೇಶ, ಗ್ರಹ, ನಕ್ಷತ್ರ, ಯೋಗಿನೀ, ರಾಶಿ, ಪೀಠ ಮಾತೃಕಾನ್ಯಾಸ), ಶ್ರೀಚಕ್ರ ನವಾಶ್ರಾವರಣ ಪೂಜೆ, ಕಾಮಕಲಾ ಧ್ಯಾನ. | ಪುಟ ೧೪೩ - ೧೫೨ |
| **ತರಂಗ ೧೨** | **ಶ್ರೀ ದುರ್ಗಾ, ಶೂಲಿನೀ ಹಾಗೂ ಮಹಿಷಮರ್ದಿನೀ ಮಂತ್ರಗಳು**<br>ದುರ್ಗಾ ನವಾರ್ಣ, ಜಯದುರ್ಗಾ, ಶೂಲಿನೀ ದುರ್ಗಾ, ಮಹಿಷಮರ್ದಿನೀ, ವನದುರ್ಗಾ, ಆಸುರೀ ದುರ್ಗಾ, ದುರ್ಗಾ ಕವಚ, ರಕ್ಷಾ ಪ್ರಯೋಗಗಳು. | ಪುಟ ೧೫೨ - ೧೫೯ |
| **ತರಂಗ ೧೩** | **ಶ್ರೀ ಹನುಮನ್ಮಂತ್ರ, ಕವಚ ಹಾಗೂ ಯಂತ್ರಗಳು**<br>ಆಂಜನೇಯ ಮಂತ್ರಗಳು, ಪಂಚಮುಖೀ ಹನುಮಾನ್, ಏಕಾದಶಮುಖೀ ಹನುಮಾನ್, ಹನುಮತ್ ಕವಚ, ಯಂತ್ರ, ಭೂತ-ಪ್ರೇತ-ಗ್ರಹಬಾಧಾ ನಿವಾರಣೆ, ಶತ್ರುಜಯ. | ಪುಟ ೧೫೯ - ೧೬೮ |
| **ತರಂಗ ೧೪** | **ಶ್ರೀ ವಿಷ್ಣು, ನಾರಾಯಣ, ನೃಸಿಂಹ ಹಾಗೂ ಗರುಡ ಮಂತ್ರಗಳು**<br>ಅಷ್ಟಾಕ್ಷರ ನಾರಾಯಣ, ದ್ವಾದಶಾಕ್ಷರ ವಾಸುದೇವ, ಉಗ್ರ ನೃಸಿಂಹ, ಲಕ್ಷ್ಮೀ ನೃಸಿಂಹ, ಗರುಡ ಮಂತ್ರ, ವಿಷಹರ ಪ್ರಯೋಗ, ಜಯಲಕ್ಷ್ಮೀ ಪ್ರಾಪ್ತಿ. | ಪುಟ ೧೬೮ - ೧೭೫ |
| **ತರಂಗ ೧೫** | **ಶ್ರೀ ಸೂರ್ಯ, ಸೌರ ಹಾಗೂ ಮಾರ್ತಾಂಡ ಮಂತ್ರಗಳು**<br>ಸೂರ್ಯ ಅಷ್ಟಾಕ್ಷರ, ಆದಿತ್ಯ ಹೃದಯ, ಮಾರ್ತಾಂಡ ಭೈರವ, ಸೌರ ಯಂತ್ರ, ರೋಗ-ಕುಷ್ಠ-ನೇತ್ರರೋಗ ನಿವಾರಣ ಮತ್ತು ತೇಜೋವೃದ್ಧಿ ಸೂರ್ಯೋಪಾಸನೆ. | ಪುಟ ೧೭೫ - ೧೮೭ |
| **ತರಂಗ ೧೬** | **ಶ್ರೀ ಶಿವ, ಮಹಾಮೃತ್ಯುಂಜಯ ಹಾಗೂ ನೀಲಕಂಠ ಮಂತ್ರಗಳು**<br>ಶಿವ ಪಂಚಾಕ್ಷರೀ, ಮಹಾಮೃತ್ಯುಂಜಯ, ನೀಲಕಂಠ, ತ್ರಯೋದಶಾಕ್ಷರ, ಪಾಶುಪತಾಸ್ತ್ರ, ಆಯುರ್ವೃದ್ಧಿ, ಅಕಾಲಮೃತ್ಯು ಹರಣ, ಮೋಕ್ಷಸಾಧನೆ. | ಪುಟ ೧೮೭ - ೧೯೫ |
| **ತರಂಗ ೧೭** | **ಶ್ರೀ ಕಾರ್ತವೀರ್ಯಾರ್ಜುನ ಮಹಾಮಂತ್ರ ಹಾಗೂ ದೀಪದಾನ**<br>ಕಾರ್ತವೀರ್ಯಾರ್ಜುನ ಮಂತ್ರ, ದೀಪದಾನ ವಿಧಿ, ನಷ್ಟದ್ರವ್ಯ-ಹೋದ ವಸ್ತು-ವ್ಯಕ್ತಿ ಪುನಃ ಪ್ರಾಪ್ತಿ, ಯಂತ್ರ, ಕವಚ, ಚೋರಭಯ ನಿವಾರಣೆ. | ಪುಟ ೧೯೫ - ೨೦೯ |
| **ತರಂಗ ೧೮** | **ಶ್ರೀ ಚಂಡೀ ನವಾರ್ಣ, ಸಪ್ತಶತೀ ಹಾಗೂ ಶತಚಂಡೀ ವಿಧಾನ**<br>ನವಾರ್ಣ ಮಂತ್ರ, ದುರ್ಗಾ ಸಪ್ತಶತೀ ಪಾರಾಯಣ ಕ್ರಮ, ಅಂಗನ್ಯಾಸ, ಶತಚಂಡೀ-ಸಹಸ್ರಚಂಡೀ ಯಜ್ಞ ವಿಧಾನ, ಸಂಪುಟೀಕರಣ, ಸರ್ವಾರಿಷ್ಟ ಶಾಂತಿ. | ಪುಟ ೨೦೯ - ೨೧೯ |
| **ತರಂಗ ೧೯** | **ಶ್ರೀ ತಾಮ್ರಚೂಡ, ಅಗ್ನಿ, ಶಾಸ್ತಾ, ಕುಬೇರ ಹಾಗೂ ಪಾರ್ಥಿವಲಿಂಗ ಪೂಜೆ**<br>ತಾಮ್ರಚೂಡ, ಅಗ್ನಿ ಮಂತ್ರಗಳು, ಶಾಸ್ತಾ (ಅಯ್ಯಪ್ಪ), ಕುಬೇರ, ಔಷಧ ಮಂತ್ರಗಳು, ಪಾರ್ಥಿವಲಿಂಗ ನಿರ್ಮಾಣ, ಪೂಜಾವಿಧಾನ, ಲಕ್ಷಣ, ಲಕ್ಷಲಿಂಗಾರ್ಚನಾ ಫಲ. | ಪುಟ ೨೧೯ - ೨೨೮ |
| **ತರಂಗ ೨೦** | **ಯಂತ್ರ ನಿರ್ಮಾಣ, ಚಕ್ರ ರಚನೆ ಹಾಗೂ ಮಂತ್ರ ಮರ್ಮಗಳು**<br>ಯಂತ್ರ ನಿರ್ಮಾಣ ವಿಧಿ, ರೇಖಾ-ಕೋಷ್ಟಕ ಲಕ್ಷಣ, ದೇವತಾ ಯಂತ್ರ ಪ್ರಾಣಪ್ರತಿಷ್ಠೆ, ಯಂತ್ರ ಧಾರಣ ಕ್ರಮ, ಸರ್ವರಕ್ಷಾ ಯಂತ್ರಗಳು. | ಪುಟ ೨೨೮ - ೨೩೯ |
| **ತರಂಗ ೨೧** | **ಸರ್ವದೇವ ಸಾಧಾರಣ ನಿತ್ಯಪೂಜಾ ಕ್ರಮ**<br>ಶಂಖ, ಘಂಟಾ, ದೀಪ ಪೂಜೆ, ಆವಾಹನಾದಿ ಷೋಡಶೋಪಚಾರ ವಿವರಣೆ, ತರ್ಪಣ, ಅರ್ಘ್ಯ, ನೈವೇದ್ಯ, ಆರತಿ, ಪಂಚೋಪಚಾರ & ಷೋಡಶೋಪಚಾರ ಕ್ರಮ. | ಪುಟ ೨೩೯ - ೨೫೧ |
| **ತರಂಗ ೨೨** | **ಮಂತ್ರಗಳ ದಶ ಸಂಸ್ಕಾರಗಳು ಹಾಗೂ ದೋಷ ಪರಿಹಾರ**<br>ಜನನ, ಜೀವನ, ತಾಡನ, ಬೋಧನ, ಅಭಿಷೇಕ, ವಿಮಲೀಕರಣ, ಆಪ್ಯಾಯನ, ತರ್ಪಣ, ದೀಪನ, ಗುಪ್ತಿ - ದಶ ಮಂತ್ರ ಸಂಸ್ಕಾರಗಳು, ಮಂತ್ರ ದೋಷ ಪರಿಹಾರ ವಿಧಿ. | ಪುಟ ೨೫೧ - ೨೫೭ |
| **ತರಂಗ ೨೩** | **ಪವಿತ್ರಾರೋಪಣ ಹಾಗೂ ದಮನೋತ್ಸವ ವಿಧಿ**<br>ಪವಿತ್ರಾರೋಪಣ ಲಕ್ಷಣ, ಸೂತ್ರ ನಿರ್ಮಾಣ, ದಮನೋತ್ಸವ (ದವನ ಪೂಜೆ), ವರ್ಷಪೂರ್ತಿ ಪೂಜಾ ನ್ಯೂನತಾ ನಿವಾರಣೆ. | ಪುಟ ೨೫೭ - ೨೭೦ |
| **ತರಂಗ ೨೪** | **ಯಾಗಮಂಟಪ, ಕುಂಡ ಲಕ್ಷಣ ಹಾಗೂ ಯಜ್ಞ ವಿಧಿ**<br>ಯಾಗಮಂಟಪ ರಚನೆ, ಕುಂಡ ಲಕ್ಷಣ (ಯೋನಿ, ವೃತ್ತ, ತ್ರಿಕೋಣ, ಚತುರಶ್ರ, ಪದ್ಮ, ಅಷ್ಟಕೋಣ), ಮೇಖಲಾ ಲಕ್ಷಣ, ಸ್ರುಕ್-ಸ್ರುವ ನಿರ್ಮಾಣ. | ಪುಟ ೨೭೦ - ೨೭೩ |
